# 校园失物招领

2026 秋软件工程第二次结对作业。基于第一次结对作业的原型，实现核心功能：发布信息、浏览/搜索、查看详情、联系发布者、更新状态。

## 目录结构

- index.html — 入口页面
- test.html — 单元测试页面
- assert.js — 轻量级断言库
- css/style.css — 样式
- js/data.js — 常量与初始数据
- js/utils.js — 工具函数
- js/app.js — 页面渲染与交互
- img/ — 物品图片

## 使用说明

### 运行网页

1. 下载整个项目文件夹
2. 双击 index.html，用谷歌 Chrome 浏览器打开
3. 即可体验完整功能

### 运行单元测试

1. 双击 test.html，用浏览器打开
2. 按 F12 打开开发者工具 若按F12没反应，尝试Fn + F12 ，打开开发者工具即可看到测试结果
3. 点击 Console 标签查看测试结果
4. 绿色 ✅ 表示通过，红色 ❌ 表示失败

## 功能说明

- 首页：按寻物/招领切换浏览
- 搜索：按名称、地点、描述关键词实时筛选
- 详情：查看物品信息、联系电话，支持一键拨号
- 发布：填写表单，选择分类和地点，支持图片上传
- 我的发布：可删除或标记已找回/已认领，同步移除首页记录

## 附加特点

1. 智能匹配推送：发布寻物时自动匹配疑似对应的招领信息
2. 图片上传：支持本地图片上传并即时预览，未上传用灰色占位图
3. LocalStorage 持久化：刷新页面后数据不丢失
4. 底部选择器：分类、地点用底部弹层选择，减少手动输入
5. 拨打中弹窗：点击打电话后全屏显示拨号界面，带波纹动画
6. 状态同步：我的发布删除或标记后，首页和搜索页同步移除
7. 空状态提示：搜索无结果、没有发布时都有友好提示
