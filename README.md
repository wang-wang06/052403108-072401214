\## 使用说明



\### 运行网页

1\. 下载整个项目文件夹

2\. 双击 `index.html`，用谷歌 Chrome 浏览器打开

3\. 即可体验完整功能



\### 运行单元测试

1\. 双击 `test.html`，用 Chrome 浏览器打开

2\. 按 `F12` 打开开发者工具

3\. 点击 \*\*Console（控制台）\*\* 标签

4\. 查看测试结果：绿色 ✅ 表示通过，红色 ❌ 表示失败



\## 功能说明



\- \*\*首页\*\*：按"招领 / 寻物"切换浏览

\- \*\*搜索\*\*：按名称、地点、描述关键词实时筛选

\- \*\*详情\*\*：查看物品信息、联系电话，支持一键拨号

\- \*\*发布\*\*：填写表单，选择物品分类和地点类型，支持图片上传

\- \*\*我的发布\*\*：可删除或标记已找回/已认领，操作会同步移除首页对应记录



\## 附加特点



1\. \*\*智能匹配推送\*\*：发布寻物信息时，自动匹配疑似对应的招领信息并推送

2\. \*\*图片上传\*\*：支持本地图片上传并即时预览，未上传则使用灰色占位图

3\. \*\*LocalStorage 持久化\*\*：刷新页面后数据不丢失

4\. \*\*底部选择器\*\*：物品分类、地点类型使用底部弹层选择，减少手动输入

5\. \*\*拨打中弹窗\*\*：点击打电话后全屏显示拨号界面，带波纹动画

6\. \*\*状态同步\*\*：在"我的发布"删除或标记后，首页和搜索页同步移除

7\. \*\*空状态提示\*\*：搜索无结果、没有发布时都有友好提示
