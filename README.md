# 校园失物招领

2026 秋软件工程第二次结对作业。基于第一次结对作业的原型，实现核心功能：发布信息、浏览/搜索、查看详情、联系发布者、更新状态。

## 目录结构

```
campus-lost-found/
├── index.html          主入口页面，双击运行
├── test.html           单元测试页面
├── assert.js           轻量级断言库（供 test.html 使用）
├── README.md           项目说明文档
├── .gitignore          Git 忽略配置
├── css/
│   └── style.css       全部样式（页面布局、配色、动画）
├── js/
│   ├── data.js         常量、初始数据、LocalStorage 持久化
│   ├── utils.js        工具函数（Toast、时间、选择器、弹窗）
│   └── app.js          页面渲染与交互逻辑
└── img/
    ├── 黑色双肩包.png
    ├── 学生卡.png
    ├── 蓝牙耳机.png
    ├── 钥匙串.png
    ├── 雨伞.png
    └── 身份证.png
```

**目录组织说明**：

- **按职责分层**：项目把代码按职责分成三层——`js/data.js` 负责数据（常量、初始数据、持久化），`js/utils.js` 负责通用工具（Toast、时间、选择器、弹窗），`js/app.js` 负责页面渲染与交互。这样修改某一层时不会影响其他层。
- **结构与样式分离**：`index.html` 只负责页面骨架，`css/style.css` 只负责外观。调整配色或布局时只改 CSS，不动 HTML。
- **页面与测试分离**：`index.html` 是主入口，`test.html` 是独立的测试入口，配套 `assert.js` 提供断言能力。两者互不干扰，运行测试不影响主程序的运行。
- **素材集中管理**：所有物品图片统一放在 `img/` 目录，代码通过相对路径 `img/xxx.png` 引用。新增物品图片时只需放入该目录，无需改动其他位置。
- **配置与文档**：`README.md` 提供项目说明，`.gitignore` 声明不需要纳入版本控制的文件（如编辑器缓存、日志）。
- **技术栈**：全部使用原生 HTML、CSS 和 JavaScript 实现，没有引入第三方框架。


## 使用说明

### 运行网页

1. 下载整个项目文件夹
2. 双击 index.html，用谷歌 Chrome 浏览器打开
3. 即可体验完整功能

### 运行单元测试

1. 双击 test.html，用浏览器打开
2. 按 F12 打开开发者工具 若按F12没反应，尝试Fn + F12 ，打开开发者工具即可看到测试结果
3. 点击 Console 标签查看测试结果
4. 绿色 ✅ 表示通过，红色 ❌ 表示失败

## 功能说明

- 首页：按寻物/招领切换浏览
- 搜索：按名称、地点、描述关键词实时筛选
- 详情：查看物品信息、联系电话，支持一键拨号
- 发布：填写表单，选择分类和地点，支持图片上传
- 我的发布：可删除或标记已找回/已认领，同步移除首页记录

## 附加特点

1. 智能匹配推送：发布寻物时自动匹配疑似对应的招领信息
2. 图片上传：支持本地图片上传并即时预览，未上传用灰色占位图
3. LocalStorage 持久化：刷新页面后数据不丢失
4. 底部选择器：分类、地点用底部弹层选择，减少手动输入
5. 拨打中弹窗：点击打电话后全屏显示拨号界面，带波纹动画
6. 状态同步：我的发布删除或标记后，首页和搜索页同步移除
7. 空状态提示：搜索无结果、没有发布时都有友好提示
